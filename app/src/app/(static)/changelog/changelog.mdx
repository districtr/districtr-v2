
## v2.3.0

**August 2026**

**Districtr v2 is now live at districtr.org!** The original Districtr remains available at [legacy.districtr.org](https://legacy.districtr.org).

**New features**

- Map modules for all 52 geographies: 50 states, DC, and Puerto Rico
- Draw and Super Draw edit modes
- Continuous choropleth scales for demographic and election shading
- City boundaries as an optional overlay layer
- Check for unassigned units while zoomed out
- Site architecture revamp with a surfaced guide page and contextual help across the map editor

**Reliability and bug fixes**

- CSV importer now infers map modules correctly and prefers customizable-district maps
- Hotkeys no longer allow assigning district 0
- Fixed a memory issue with voting age population overlays
- Gentler zoom animations

**Security**

- Cloudflare Turnstile integration to protect map creation
- Completed a security audit
