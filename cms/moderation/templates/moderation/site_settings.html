Maintenance mode

When enabled, the public site redirects visitors to the under-construction page and the backend API answers 503 to everything except site settings, so in-flight edits stop saving. Tabs already open show a blocking maintenance notice (with the banner text) within about a minute, and drop it once maintenance ends. The frontend caches this flag for up to a minute, the API for up to 15 seconds. This admin stays reachable, but its tools that call the API (submission moderation, imports, overlays, thumbnails) are paused too.

Workflow: start a countdown (say 10 minutes) to warn people mid-edit. When it runs out, switch maintenance on and wait a few minutes before starting database work, so open tabs and in-flight requests settle. Expect the load balancer's 5xx alarm email: the paused API's 503s count. Afterwards, switch maintenance off and clear the banner text (one Save does both). The switch lives in the database, so restoring a snapshot turns it off: switch it back on first.
