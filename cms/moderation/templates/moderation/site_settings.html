Shown at the top of every page, including the map editor — use it for downtime notices. Leave blank to hide it. Visitors can dismiss a message; changing the text shows it again. Open tabs pick up a change within about five minutes.

Maintenance mode

When enabled, the public site redirects visitors to the under-construction page and the backend API answers 503 to everything except site settings, so in-flight edits stop saving. Tabs already open show a blocking maintenance notice (with the banner text) within about five minutes, and drop it once maintenance ends. The frontend caches this flag for up to a minute, the API for up to 15 seconds. This admin stays reachable, but its tools that call the API (submission moderation, imports, overlays, thumbnails) are paused too.

Workflow: post a banner first to warn people mid-edit. Then switch maintenance on and wait 5–10 minutes before starting database work, so open tabs and in-flight requests settle.
